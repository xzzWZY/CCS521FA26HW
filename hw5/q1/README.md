# HW5 Problem 1: Explanations

Starter code for inference with the pretrained ResNet-18 model of PyTorch.

- `imagenet_resnet_infer.py`: loads ResNet-18, preprocesses the images and prints the predicted class of each image.
- `imagenet_class_index.json`: the mapping from the class index to the ImageNet synset and label.

Download the ImageNet samples from the link in the homework and put them in the folder `imagenet_samples` next to the script (one folder for each class). Then run:

```bash
python imagenet_resnet_infer.py
```
